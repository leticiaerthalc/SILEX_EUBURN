# PhD Thesis Data Products

Data products produced during my PhD thesis within the
[EUBurn](https://euburn.aeris-data.fr/) project.

- **Project:** EUBurn – the southern Europe biomass burning project
- **Thesis:** Characterization of aerosols released by wildfires in Europe and
  their regional climate impact, Université de Toulouse / Météo-France – CNRM, 2028
- **Author:** Leticia Erthal Cordeiro ([ORCID](https://orcid.org/0000-0001-8559-7851))

## Products

| Folder | Description | DOI |
|--------|-------------|-----|
| [`Atmospheric_Layer_Classification/`](Atmospheric_Layer_Classification/) | Flight-by-flight classification of the atmospheric layers sampled during the SILEX campaign (v1: manual; v2: manual + K-Means) | [10.5281/zenodo.24529089](https://doi.org/10.5281/zenodo.24529089) |

More products will be added as separate folders, each with its own README
